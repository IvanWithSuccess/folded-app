# Архитектура и функционал `Folded Cloud`

Ниже приведено подробное описание архитектуры, текущего функционала и технических решений, внедренных в приложение.

## 1. Ядро: Хранение и Файловый Движок (Rust)
- **Кластеризация (Intelligent Chunking):** Приложение автоматически разбивает файлы любого объема на бинарные фрагменты (до 1.9 ГБ или до 3.9 ГБ для Telegram Premium), обходя лимиты платформы и обеспечивая целостность данных.
- **Локальный Мета-Индекс (SQLite):** Высокопроизводительная база данных (`metadata_db.sqlite`), использующая `SQLx`, которая хранит дерево виртуальной файловой системы и связывает его с распределенными сообщениями в Telegram.
- **Мультиаккаунтовость (Storage Nodes):** Поддержка неограниченного числа подключенных Telegram-аккаунтов. Облако объединяет их в единый кластер, где каждый аккаунт выступает как независимая нода хранения.
- **Background Sync Engine (Crawler):** Автономный фоновый процесс, который рекурсивно индексирует "Избранное" (Saved Messages), обновляя локальную базу данных без участия пользователя.

## 2. WebDAV и Системная Интеграция (Rust)
- **WebDAV Bridge:** Реализация протокола WebDAV, которая транслирует запросы операционной системы напрямую в вызовы Telegram API. 
- **Адаптивный Стриминг:** Поддержка "ленивой" загрузки данных. Тяжелые медиафайлы (4K видео) воспроизводятся мгновенно, так как чанки скачиваются по мере запроса плеером (Range Requests).
- **Native OS Mount:** Автоматическое монтирование облака как сетевого диска (Finder на macOS, Проводник на Windows) через системные утилиты.
- **Устойчивость Соединения:** Автоматическое переподключение WebDAV при смене сетевых интерфейсов или выходе из спящего режима.

## 3. Стабильность и Безопасность
- **Отказоустойчивость UI:** Внедрена система "Харденинга" фронтенда против гонок состояний (Race Conditions). Глобальный перехватчик `unhandledrejection` и защита `isMounted` гарантируют отсутствие вылетов при логауте или удалении данных.
- **Локальное Хранение:** Сессионные файлы Telegram (`.session`) хранятся исключительно локально в `~/.folded/sessions/`. Приложение не использует промежуточных серверов.
- **Безопасная Авторизация:** Поддержка QR-кодов, SMS-кодов и двухфакторной аутентификации (2FA) напрямую через зашифрованные каналы MTProto.

## 4. Пользовательский Интерфейс (Industrial Design)
- **FileManager v2:** Интеллектуальный менеджер с фильтрацией по категориям (Фото, Документы, Избранное) и поддержкой системных превью.
- **Cloud Notes:** Система заметок, интегрированная с облаком. Позволяет прикреплять файлы из хранилища к текстовым записям, синхронизируя их через инфраструктуру Telegram.
- **System Tray:** Полноценный демон в системном трее, позволяющий WebDAV-серверу работать даже при закрытом основном окне.
- **Advanced Settings:** Тонкая настройка параллельных потоков загрузки, лимитов кэша и портов WebDAV.

## 🚀 Вектор развития (Roadmap)

1. **WebDAV Write Support (R/W)**
   - Реализация загрузки файлов через монтированный диск ( Finder -> Drag & Drop -> Cloud).
2. **End-to-End Encryption (E2EE)**
   - Шифрование чанков "на лету" перед отправкой в Telegram с использованием мастер-пароля (AES-256).
3. **Smart Search & OCR**
   - Индексация текстового содержимого документов и распознавание текста на изображениях для быстрого поиска.
4. **Mobile Companion**
   - Упрощенная мобильная версия для быстрого доступа к файлам и заметкам в дороге.
5. **Shared Links (P2P)**
   - Генерация ссылок для обмена файлами между пользователями Folded Cloud без пересылки сообщений вручную.
