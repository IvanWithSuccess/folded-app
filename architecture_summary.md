# Архитектура и функционал `Folded Cloud`

Ниже приведено подробное описание всего текущего функционала и архитектуры приложения.

## 1. Ядро: Хранение и Файловый Движок (Rust)
- **Кластеризация (Chunking):** Приложение автоматически разбивает большие файлы на бинарные чанки (размером до 1.9 ГБ или до 3.9 ГБ при наличии Telegram Premium), чтобы обойти ограничения Telegram.
- **SQLite Мета-Кэш:** Полностью локализованная база данных (`metadata_db.sqlite`), которая отслеживает связи между виртуальными файлами/папками и реальными сообщениями в Telegram.
- **Мультиаккаунтовость:** Поддержка неограниченного числа подключенных аккаунтов. Файлы в виртуальной файловой системе изолируются по папкам (названия папок соответствуют `username` аккаунтов).
- **Background Sync Engine:** Движок (Crawler), который работает в фоне и регулярно рекурсивно проверяет `Saved Messages` каждого аккаунта для подгрузки новых файлов (на основе `last_indexed_at`), минуя UI.

## 2. WebDAV и OS Интеграция (Rust)
- **Локальный WebDAV Сервер:** Поднимает сервер (по умолчанию на порту 9876), который эмулирует файловую систему.
- **Абсолютный Streaming:** Позволяет открывать тяжелые файлы (например, фильмы 4K) напрямую с серверов Telegram через WebDAV, без полного предварительного скачивания файла на диск. Чанки скачиваются по требованию медиаплеера.
- **Native OS Mount:** Приложение автоматически монтирует WebDAV сервер как реальный диск или сетевую папку (Finder на macOS, `net use` на Windows).
- **System Tray Daemon:** Приложение может жить в системном трее, обеспечивая бесперебойную работу WebDAV, даже когда основное окно интерфейса закрыто.

## 3. Авторизация (Rust + Grammers + TS)
- Прямая работа с API Telegram через библиотеку **Grammers**.
- Поддержка входа через **QR-код** (динамическая генерация и рендеринг SVG на фронтенде).
- Поддержка **2FA** паролей (Облачный пароль Telegram).

## 4. Пользовательский Интерфейс (React + Tailwind + Tauri)
- **Sidebar Навигация:** Разделение по "Дискам" (аккаунтам) и категориям файлов.
- **Smart FileManager:** Отображение файлов списком с иконками, кнопками скачивания, системного открытия и удаления. Интеллектуальный фильтр по категориям: *Photos* (картинки), *Documents* (всё остальное), *Starred* (избранное — пока задел на будущее).
- **Account Center:** Виджеты для управления аккаунтами, переподключения или отключения узлов.
- **Notes (Заметки):** Простая система заметок, похожая на сам Telegram. Позволяет писать текст, прикреплять уже загруженные в облако файлы и удалять заметки. Поддерживается `Read-Only` режим для форварднутых заметок.
- **Global Settings:** Настройка директории скачивания по умолчанию (Native Dialog Picker), кастомизация WebDAV порта и чанковки, управление сворачиванием в трей и полное стирание локального кэша базы данных (Danger Zone).

## 💡 Идеи для новых фишек и развития (Brainstorm)

1. **Загрузка через WebDAV (Read/Write)**
   - *Сейчас:* WebDAV (монтированный диск) работает в режиме Read-Only (только чтение).
   - *Цель:* Реализовать обработчик PUT/POST запросов в `dav-server`. Когда пользователь кидает файл в сетевой диск из Finder, `WebDavBridge` ловит файл, режет его на чанки и сразу аплоудит в Telegram.
2. **Параллельная Трансферная Сеть (Sharing)**
   - Создать систему "Шеринга". Так как данные хранятся в Telegram, можно позволить поделиться файлом с другим пользователем `Folded Cloud`, просто переслав ему ID сообщения.
3. **End-to-End Encryption (E2EE)**
   - Внедрить шифрование на лету! При разбитии файла на чанки, шифровать каждый чанк AES-256 с мастер-паролем перед отправкой в "Избранное". Telegram вообще не будет знать, что за файлы вы храните.
4. **Offline Mode с частичным кэшированием**
   - Кнопка "Make available offline" в интерфейсе. При нажатии, файл полностью скачивается в невидимую локальную папку и отдается локально с нулевой задержкой.
5. **Редизайн Заметок (Markdown / Notion-like)**
   - Расширить редактор заметок, добавив блочный формат (как в Notion) или хотя бы поддержку Markdown с предпросмотром.
